# Fuzz image dependencies. Keep this separate from normal dev dependencies
# because Atheris wheels are platform-specific.
#
# atheris 3.1.0 ships cp312/cp313/cp314 manylinux x86_64 wheels; it dropped the
# cp311 wheel and ships no sdist. atheris 3.0.0 has no cp314 wheel, so any
# wheel-only CPython 3.14 environment cannot install it. This repo's fuzz image
# and clusterfuzzlite run on CPython 3.12, where 3.1.0 also has a wheel, so the
# bump is safe here while staying installable on newer interpreters. Hashes
# below cover the cp312/cp313/cp314 Linux x86_64 wheels.

atheris==3.1.0 ; platform_system == "Linux" and platform_machine == "x86_64" \
